Demo Documentation / Admin Panel

Admin Panel Guide

The admin panel is where the gym runs its website: new bookings, offers, member reviews, announcements and timings, all without touching code or paying a developer for small changes.

Where the admin panel is

Two ways to open it:

  • Scroll to the bottom of any website page: the footer has an Admin Panel link.
  • Or open the address directly: badu10m-code.github.io/ironpulse-demo/admin.html

There is no password in this demo. The yellow notice at the top explains it: this is a demo panel, and everything saved in it stays in the browser you are using. On the real website the panel is protected by a login and only your staff can reach it.

Dashboard

The first screen: live counts of trial bookings, custom testimonials, WhatsApp members and active offers, plus the latest trial requests.

Trial Bookings

Every booking from the website lands here with its booking ID, name, phone, goal and preferred time. Staff can add walk-in and phone bookings manually, open a WhatsApp chat with any booking in one tap, or delete a booking.

Offers

Type a badge, a title and the details, save, and the homepage grows a Running Offers section with a Claim Offer button. Offers can be hidden or shown again without deleting them.

Testimonials

Add a member's name, a tag and the review. Custom reviews replace the sample ones on the homepage, up to eight.

Announcement

One line of text becomes a yellow strip across the top of every page: perfect for festive offers, camp announcements or holiday timings.

Timings

Change the opening hours shown in the locations section and the footer. Leave the fields blank to return to the defaults.

WhatsApp Blast

Keep a list of members, write one message draft, and send it to any member with one tap: festive offers, holiday closures, camp reminders.

Data and Reset

Export everything as a JSON file, or reset the demo data to empty.

Try it yourself in 5 minutes

  1. Open the Admin Panel and look at the Dashboard.
  2. Under Offers, add one offer with any badge and title, then open the homepage and scroll to Running Offers.
  3. Under Announcement, type an offer line and save, then reload any page and see the yellow strip.
  4. Open the Contact page and book a trial with any name: watch it appear in the Admin Dashboard.
  5. Open the yellow My Booking button on the website and see the same booking from the customer's side.
One thing to know: demo data lives in the browser you use. A booking made on your phone shows in the admin panel opened on that same phone. On the live website this becomes a real database, so every device sees the same data.
